# M.A.R.V.E.L. — Teroka Kata, Bongkar Makna!

Inovasi pedagogi digital gamifikasi untuk Bahasa Melayu Tahun 3.

Fokus:
- SK 2.2 Membaca, memahami, dan menaakul bahan grafik dan bukan grafik.
- SP 2.2.1 Membaca, memahami, dan mengecam maksud kosa kata.
- Sasaran inklusif: murid ADHD.
- Elemen: gamifikasi, visual, konteks makna, aksesibiliti dan maklum balas segera.

Versi awal ini menggunakan HTML, CSS dan JavaScript tanpa binaan server, sesuai untuk GitHub Pages.
